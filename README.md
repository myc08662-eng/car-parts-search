Car Parts Search
Веб-сервис для поиска автозапчастей по названию и автомобилю с умным ранжированием, парсингом цен и инструкциями по ремонту.

Стек технологий
Компонент	Технология
Бэкенд	FastAPI (Python 3.14)
Поиск	scikit-learn (TF‑IDF, косинусное сходство)
База данных	MySQL
Парсинг	httpx, BeautifulSoup4
Тестирование	pytest, pytest-mock
Кэширование	In‑memory TTL‑кэш
Шаблоны	Jinja2

Функциональность
Умный поиск

Использует TF‑IDF и косинусное сходство для ранжирования результатов.

Обрабатывает синонимы (например, «масляный» в «oil») и транслитерацию (кириллица в латиница).

Поддерживает фильтрацию по категориям и пагинацию.

Парсинг актуальных цен

Автоматически обновляет цены с сайтов-магазинов (tachka.ru, amag.ru, startvolt.com, ruli.ru и др.).

Работает ротация User‑Agent и случайная задержка для снижения риска блокировки.

При ошибках парсинга или ценах ниже порога (50 ₽) используется запасная цена из БД.

Инструкции по ремонту

Для каждого автомобиля доступны PDF‑руководства.

Реализовано скачивание с защитой от path‑traversal.

Кэширование результатов

In‑memory кэш с TTL = 60 секунд ускоряет повторные поисковые запросы.

Безопасность

Экранирование вывода во фронтенде.

Ограничение длины поискового запроса (макс. 200 символов).

Параметризованные SQL‑запросы для защиты от инъекций.
